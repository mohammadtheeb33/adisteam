# Phase 1 development

Use Python 3.12. Create a virtual environment and install `python -m pip install -e . --group dev`.
Copy `.env.example` to `.env` and configure the collection, broker and database settings.
The database schema has only `agents` and `security_events`, plus Alembic's revision table.

```
python -m alembic upgrade head
python scripts/kafka_create_topics.py
python -m apps.api
python -m apps.normalizer
python -m apps.agent run
python -m pytest tests/unit
```

`docker compose --profile app up -d --build` runs the ingestion API and normalizer with infrastructure.
The original real-data collector laboratory is in `infrastructure/lab/compose.yaml`; use
`python scripts/lab_phase1.py up`. Its historical results are preserved in `.adis-lab/final`.
The lab uses the original compose project name and ports; do not run two instances together.
Integration tests require disposable service URLs, never the source database.
