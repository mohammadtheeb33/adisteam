4. قرارات التصميم

القرارالسبب
إعادة تسمية الـ topics الثلاثة الخام فقط إلى أسماء المواصفةالـ Normalizer وحده يقرأها، فالمراحل 2–7 (التي تقرأ adis.security.events) لا تتأثر. مسجّل كقرار OD-39.
لا تغيير في المخطط canonical v1.0استدعاءات النظام أحداث process، وسلوك المستخدم أحداث authentication.session_*. هكذا لا تحتاج المراحل اللاحقة لأي تعديل.
فقط authentication.login* تُعدّ محاولات دخولحتى لا تُضخّم أحداث الجلسات والخروج ميزات الدخول في Phase 2.
تدفقات ثنائية الاتجاهالمخطط الموحد يحمل bytes_sent و bytes_received، وميزات Phase 2 تعدّ «الاتصالات»؛ تدفقا muna الأحاديان كانا سيُعدّان اتصالين.
الـ Agent لا يحتاج صلاحياتالمشغّل يثبّت قواعد audit أو يشغّل bpftrace، والـ Agent يقرأ الملف الناتج فقط (أقل صلاحية).
المصادر المركزية (Syslog، NetFlow) تعمل كوكيل بتوكن غير مربوط بجهازلأنها تكتب أحداث أجهزة أخرى (اسم المرسل أو المُصدِّر هو host_id).
معرّفات أحداث حتميةمن حقائق المصدر (الحاسوب والقناة ورقم السجل، أو 5-tuple ووقت أول حزمة)، فيمنع الـ Normalizer التكرار عند إعادة القراءة.

5. الأمان والخصوصية

الجمع

  • كل مجمّع مغلق افتراضيًا.
  • الالتقاط الحي يحتاج واجهة محددة بالاسم و AGENT_LIVE_CAPTURE_AUTHORIZED=true؛ promiscuous مطفأ إلا مع شبكات مختبر محددة.
  • رؤوس الحزم فقط (snaplen 160)، ولا تُحلّل البيانات.
  • حركة الـ Agent نفسه إلى الـ API و Kafka مستثناة.

الاستماع

  • Syslog و NetFlow على عنوان واحد، loopback إلا بإذن صريح، ولا 0.0.0.0 أبدًا.
  • Syslog من مرسلين مسموحين فقط؛ NetFlow من مُصدِّرات مسموحة فقط.
  • رسائل Syslog محدودة الحجم.

الخصوصية

  • حقول تشبه الأسرار تُحذف والنصوص تُنقّح.
  • اسم الحساب غير الموجود (قد يكون كلمة مرور) يُحجب من الحدث ومن كل سطور sshd: 0 تسريب في البيانات الحقيقية.
  • وسائط أوامر العمليات لا تُجمع أبدًا.
  • SIDs الشخصية لا تُرسل.

سجل Security الحقيقيمرفوض بلا صلاحية؛ المجمّع يبلّغ «access denied» ويعيد المحاولة كل 60 ثانية والقنوات الأخرى تعملتشغيل الوكيل كعضو في «Event Log Readers» أو كمسؤول
الالتقاط الحي على Windowsيحتاج Npcap (غير مثبت؛ الوكيل لا يثبّت تعريفات). اختُبر على Linux بـ libpcapتثبيت Npcap من npcap.com
«ملايين الرسائل/ثانية» و MTTD < 50 msغير مثبتين (رقمان من الأبحاث)تعديل الأهداف في المواصفة إلى أرقام مقاسة
وكيل بهوية جديدة يعيد قراءة التاريختكرارات متعارضة إلى dead-letter (لا تخزين مكرر)قرارك: هل يتجاهل الـ Normalizer agent_id عند المقارنة؟

بيانات omranبلا TCP flags وبلا منطقة زمنية؛ اعتُبرت أوقاتها UTC—
