1. الخلاصة التنفيذية

أقوى منصة

المشروع الأساسي (D:\pentra)

  • خط أنابيب كامل ومُتحقَّق منه: Agent ← FastAPI ← Kafka ← Normalizer ← Supabase/PostgreSQL ← Kafka.
  • مصادقة بالتوكن، rate limiting عبر Redis، سجلات JSON منظمة، Prometheus، Dead-letter، Docker.
  • نقطة الضعف الكبرى: لا يجمع بيانات أمنية حقيقية؛ الـ Agent يقرأ أسطر ملفات log فقط، وأحداث المصادقة والشبكة مُحاكاة.
أقوى جمع بيانات حقيقية

muna (ADIS-main)

  • مجمّعات حقيقية: سجلات Windows (System/Application)، المصادقة من سجل Security، ملفات PCAP، الالتقاط الحي (Npcap)، NetFlow/IPFIX عبر GoFlow2.
  • نفس أسماء الـ topics في المواصفة، قاعدة PostgreSQL غنية بأدوار صلاحيات مفصولة، 713 اختبار.
  • نقاط الضعف: نقطة الإدخال بلا مصادقة ولا rate limiting، سجلات نصية غير منظمة، Windows فقط، وشكل الحدث غير متوافق مع المشروع الأساسي.
نموذج أولي بسيط

omran

  • 4 سكربتات (181 سطرًا): التقاط حزم بـ scapy ← CSV + FastAPI ← Kafka ← طباعة.
  • يغطي حركة الشبكة فقط (1 من 4 مصادر)، بلا اختبارات ولا توثيق ولا إعدادات.
  • مشاكل خطيرة: التقاط بوضع promiscuous افتراضيًا، فقدان صامت للبيانات، تجاهل كامل لـ IPv6، وملف 15 MB من حركة شبكة حقيقية داخل المشروع.

11. نقاط القوة التي يجب الاحتفاظ بها

من المشروع الأساسي

  • المخطط الموحد canonical v1.0 مع JSON Schema مُثبت باختبار snapshot.
  • FastAPI بمصادقة لكل عميل، ربط بالأجهزة، rate limiting، حدود حجم، أخطاء بلا إرجاع المدخلات.
  • Normalizer مستقل: منع تكرار ذري، dead-letter، إعادة المحاولة عند الانقطاع.
  • Agent بـ spool مشفر و backpressure بدل الحذف.
  • سجلات JSON + trace عبر Kafka + Prometheus + Grafana + Docker compose.
  • تحقق end-to-end حقيقي مع انقطاعات حقيقية.

من muna

  • مجمّعات Windows الحقيقية مع checkpoints و retry وحماية خصوصية متقدمة (حذف الأسرار، عدم إرسال SIDs، حجب الاسم المكتوب في 4625 بحالة 0xc0000064).
  • معالج PCAP بذاكرة محدودة، IPv6، VLAN، fragments.
  • التقاط حي بضمانات أمان ممتازة (تأكيد صريح، غير promiscuous، رؤوس فقط).
  • NetFlow/IPFIX مع قائمة مُصدِّرات مسموحة، كشف الفجوات وإعادة الترتيب.
  • معرّف حدث حتمي (UUIDv5) يجعل إعادة الإرسال قابلة للتمييز.
  • أدوار قاعدة بيانات بأقل صلاحية، partitions، retention، backup مع SHA-256.
  • أدوات adis-doctor و adis-demo، وملفات اختبار بعناوين توثيقية فقط.

من omran

  • فكرة بسيطة وواضحة لمسار البيانات تصلح للشرح والتعليم.
  • عيّنة حركة حقيقية (بعد التجهيل) يمكن أن تكشف فروق «المختبر مقابل الواقع» التي تعاني منها النماذج حاليًا (P7-002).
